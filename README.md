# Marium AI Academy Landing

Ye rahi ek complete, copy-paste-able prompt jo aap kisi bhi AI website builder (ya mujhe dubara) ke saath use kar sakte hain — isi landing page ke reference ke sath:

Prompt:

Create a landing page for Marium AI Academy, a 2-month AI Automation course, exclusively for girls, taught through live, one-on-one online classes. The course is beginner-friendly — no prior programming experience required — and ends with a certificate of completion.

Brand design system (must be followed exactly):

Renewal Green #BAD435 — primary accent (buttons, links, highlights, CTAs)

Graphite Teal #002E32 — dark backgrounds / heading text

Pure White #FFFFFF — background / text on dark

Graphite Industrial #1C1C1C — deep dark section backgrounds

Cool Light Grey #F2F5F4 — soft/light section backgrounds

Headings: Kanit, Bold (700)

Body text: Poppins, Light (300)

Rule: max 3 colors per section (1 background + 1 text + 1 accent); accent is always Renewal Green; dark bg → white/grey text, light bg → teal/industrial text.

Course structure to include (Course Scope: 2 Months):

Month 1 — Programming & Integration Foundations

Programming Fundamentals — variables, data types, conditions, loops, functions, lists/dictionaries, problem solving

JSON & Data Handling — objects, arrays, nested data, transforming data between systems

APIs & Webhooks — GET/POST/PUT/DELETE, headers, auth, API keys, Postman testing, webhooks, connecting apps

Month 2 — AI Automation with n8n
4. n8n Fundamentals — nodes, workflows, triggers, expressions, IF/Switch logic, loops, error handling
5. AI Automation — OpenAI/API integration, AI agents, prompt design, structured outputs, business workflows
6. Real Integrations — Google Sheets, Gmail, Google Calendar, WhatsApp API, CRMs, external APIs
7. Real-World Projects — portfolio-ready end-to-end automation builds

Sections needed: Hero (headline + CTA to reserve seat), why-this-course / value points, full curriculum timeline (Month 1 & 2), class format (live, 1-on-1, girls-only), certificate section, seat-reservation CTA, footer.

Tone & positioning: Professional, modern, tech-forward — not cutesy or overly feminine. Emphasize exclusivity (girls-only, limited 1-on-1 seats), practical skill-building, and real project outcomes.

Design direction: Original layout — do not copy any existing site's design, only use it as loose structural reference. Use an automation/workflow-node visual motif somewhere (ties to the n8n subject matter). Fully responsive, single self-contained page.
